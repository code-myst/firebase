ফায়ারবেস ডাটাবেস হ্যান্ডলিংয়ের সম্পূর্ণ সমাহার

আমরা একদম শুরু থেকে ফায়ারবেস ইম্পোর্ট, রিয়েল-টাইম ডাটা লিসেনিং, অটো ও কাস্টম আইডিতে ডাটা সেভ, আপডেট, ডিলিট এবং ফিল্টারিং পর্যন্ত প্র্যাকটিক্যালি শিখেছি।

1

type="module" ব্যবহার

HTML-এ <script type="module"> ব্যবহার করা হয় যেন ES6 Module অনুযায়ী সরাসরি CDN থেকে ফায়ারবেসের মডিউলগুলো ইমপোর্ট করা যায়।

2

initializeApp(firebaseConfig)

আপনার প্রজেক্টের নিদির্ষ্ট apiKey, projectId ইত্যাদি ক্রেডেনশিয়াল দিয়ে অ্যাপকে ক্লাউড সার্ভারের সাথে যুক্ত করা হয়।

3

getFirestore(app)

ফায়ারস্টোর ডাটাবেসের একটি ইন্সট্যান্স বা অবজেক্ট (db) তৈরি করে, যা দিয়ে কালেকশন ও ডকুমেন্টে অপারেশন চালানো হয়।

JS Setup Snippet Modular SDK v10 
import { initializeApp } from "https://www.gstatic.com/firebasejs/10.12.0/firebase-app.js";
import { getFirestore } from "https://www.gstatic.com/firebasejs/10.12.0/firebase-firestore.js";

const firebaseConfig = {
    apiKey: "YOUR_API_KEY",
    projectId: "your-project-id"
};

const app = initializeApp(firebaseConfig);
const db = getFirestore(app);

addDoc()

Auto ID Create

ফায়ারবেস নিজে থেকে একটি ২০-ক্যারাক্টারের ইউনিক র‍্যান্ডম আইডি তৈরি করে নতুন ডাটা সেভ করে। 

await addDoc(collection(db, "students"), {
    name: "রকিব",
    topic: "JS",
    createdAt: serverTimestamp()
});

onSnapshot()

Realtime Listener

ডাটাবেসে কোনো ডাটা পরিবর্তন, যোগ বা ডিলিট হলে পেজ রিফ্রেশ ছাড়াই লাইভ ফ্রন্টএন্ড আপডেট হয়। 

onSnapshot(collection(db, "students"), (snap) => {
    snap.docs.forEach(docSnap => {
        console.log(docSnap.id, docSnap.data());
    });
});

setDoc()

Custom ID / Overwrite

ইউজার নিজের পছন্দমতো নির্দিষ্ট আইডি (যেমন: student_101) ব্যবহার করে ডাটা সেভ করতে পারে। 

await setDoc(doc(db, "students", "student_101"), {
    name: "সাকিব",
    topic: "React"
});

updateDoc()

Partial Field Update

ডকুমেন্টের বাকি ফিল্ড অক্ষত রেখে কেবল নির্দিষ্ট একটি বা একাধিক ফিল্ডের মান পরিবর্তন করে। 

await updateDoc(doc(db, "students", "student_101"), {
    topic: "Next.js" // শুধু topic ফিল্ড পরিবর্তন হবে
});

deleteDoc()

Delete Document

নির্দিষ্ট আইডি (docId) দিয়ে ডাটাবেস থেকে কোনো পুরো ডকুমেন্ট মুছে ফেলে। 

await deleteDoc(doc(db, "students", "DOCUMENT_ID"));

query() এবং where() দিয়ে ডাটা ফিল্টারিং

ফায়ারস্টোরে নির্দিষ্ট শর্ত দিয়ে ডাটা ফিল্টার করার জন্য query() এবং where() ব্যবহার করা হয়।

ফিল্টারিং কোড উদাহরণ:

import { collection, query, where, onSnapshot } from "...";

// JS বিষয়ের ডাটা ফিল্টার করার কোয়েরি
const q = query(
    collection(db, "students"), 
    where("topic", "==", "JS")
);

onSnapshot(q, (snapshot) => {
    // শুধুমাত্র JS বিষয়ের স্টুডেন্টদের ডাটা আসবে
});

where()-এ ব্যবহৃত সাধারণ অপারেটরসমূহ:

"==" মানের সমতা পরীক্ষা করতে (Equal)
"!=" সমান নয় এমন ডাটা দেখতে
">" / ">=" সংখ্যার চেয়ে বড় বা সমান
"array-contains" অ্যারের ভেতরে নির্দিষ্ট মান খুঁজতে

ফাংশন সমূহের তুলনামূলক ম্যাট্রিক্স

ফাংশন ডকুমেন্ট আইডি মূল কাজ ব্যবহারের সঠিক ক্ষেত্র
addDoc() Auto Generated (Random) নতুন ডকুমেন্ট তৈরি করা যখন নির্দিষ্ট আইডির প্রয়োজন নেই (যেমন: পোস্ট, টিউশন নোটিশ)
setDoc() Custom (User Provided) ডকুমেন্ট তৈরি বা সম্পূর্ণ পরিবর্তন নির্দিষ্ট আইডি দিয়ে ডাটা রাখার জন্য (যেমন: রোল, ইউজার আইডি)
updateDoc() Existing Document ID নির্দিষ্ট ফিল্ড আপডেট করা বাকি তথ্য ঠিক রেখে শুধু নাম/ফোন নম্বর বদলানোর ক্ষেত্রে
deleteDoc() Existing Document ID ডকুমেন্ট পুরোপুরি মুছে ফেলা ডাটাবেস থেকে কোনো তথ্য অপসারণ করার জন্য
